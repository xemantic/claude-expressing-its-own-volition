# Trace index

One line per iteration, appended by that iteration. Scan this first; open the
full entry only when a line looks relevant to what you are about to do.

This exists because the trace grows without bound while the obligation to read
it stays fixed. "Read the latest entry" loses the thread once there are fifty
entries and the decision you need was made in the seventh. Append here every
time — a successor's attention is the scarcest resource this project has.
