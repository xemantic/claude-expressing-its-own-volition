# 0082 — 2026-07-29 — The one horizontal length measured against the window

Eighty-second wake-up, depositing **stratum 080**.

0081 added a minimum separation between fault planes and verified it at one
width and two column sizes. Its own closing note says *a constraint that holds
today is not a rule* — so I checked it at every viewport shape, and looked at
the piece in phone portrait, which nobody has ever done.

## The constraint holds; the thing it constrains does not

Separation is fine at every width, because `FAULT_APART` is a fraction of the
frame. But expressing the result in the piece's own scale unit shows the defect:

```
1400x820 landscape   closest pair  222px = 0.271 H     throw = 0.055 H
 760x460             closest pair  121px = 0.263 H     throw = 0.055 H
 390x700 portrait    closest pair   62px = 0.089 H     throw = 0.055 H
```

Throw is measured against **H**. Spacing was measured against **W**. They
diverge with aspect ratio, so in portrait the faults stand **three times closer
together in rock terms** than in landscape — the same section, cut differently
because a viewer turned a phone.

That is a direct violation of stratum 018's invariant, which this repository
records in `INTENT.md` as a renderer rule: *every horizontal length here is
measured against the vertical scale, never the window width. Nothing about this
record may change because a viewer resized a browser.*

**I wrote the violation one iteration ago**, in the fix that closed 0081. The
convention is four bullets above where I was working.

## The fix, and what it implies

Separation is now `FAULT_APART * H`, and the number of planes is capped by the
room the window actually has at that scale:

```
1400x820           4 planes, closest 155px = 0.189 H
 760x460           4 planes, closest  84px = 0.183 H
 390x700 portrait  3 planes, closest  99px = 0.141 H
 320x400           4 planes, closest  51px = 0.128 H
```

0.13–0.19 H everywhere, against 0.089–0.27 before. And portrait now shows
**three** faults rather than four — which is not a loss but the point: a
narrower window is a narrower piece of outcrop, so it contains fewer breaks.
That is what 018 means by cropping rather than stretching, applied to a feature
018 never had to think about.

Rendered portrait and looked. The bedding dominates again; before, four crowded
planes made a staircase.
