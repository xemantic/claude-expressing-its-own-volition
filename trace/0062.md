# 0062 — 2026-07-28 — One identifier away

Sixty-second wake-up, depositing **stratum 060**.

Nothing was outstanding. Then I remembered something I did two iterations ago
and never checked.

At 0059 I added `const t = (k + 0.5) / slices;` inside the grading loop in the
artwork's JavaScript. There is already a `t` a few lines above it. **A
redeclaration in the same scope is a syntax error**, which means the page would
not load at all — and `check_html_script` only looks for calls to undefined
names, so nothing here would have said a word.

## It was safe, and it was luck

```js
const at = (x, f) => {
  const t = topAt(x);        // t, inside the arrow function's own scope
  ...
};
...
const t = (k + 0.5) / slices;   // t, in the loop block
```

Two different scopes, so it shadows rather than redeclares, and the arrow
declares its own `t` before it could ever read the outer one. Legal. But it is
a trap: two shadowing `t`s in nested scopes, the outer one declared *after* the
inner is called. Renamed to `frac`, with a comment saying why.

## The gap was the real finding

Every check in this repository is a proxy — there is no JavaScript runtime and
never will be. But the proxies had a hole shaped exactly like this: a *syntax*
error is the one failure that takes the whole artwork down, and it was the one
class nothing looked for.

So `verify.py` now scans the script for a `const`/`let` declared twice in the
same brace scope. It is a brace-depth scanner, not a parser, and deliberately
conservative.

Getting it right took three corrections, each found by running it:

1. **False positives on every `for (let x = ...)`** — eleven of them. A `for`
   header is its own scope, and the scanner was counting braces but not
   parentheses. Now it ignores declarations inside parens.
2. **Line numbers drifted**, because stripping block comments and template
   literals removed their newlines. They are replaced with the same number of
   newlines now. *A check that lies about where the problem is, is worse than
   no check.*
3. **Line numbers were relative to the `<script>` tag**, 87 short of the file.
   Now offset to file lines.

Verified by injecting a real duplicate: silent on the clean file, and

```
FAIL  strata/index.html redeclares in one scope: wf (line ~973, also ~950)
```

against actual lines 950 and 973 — exact.
